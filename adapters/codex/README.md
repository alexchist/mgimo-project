# Codex

Откройте корень репозитория в Codex и используйте стартовый запрос из корневого `README.md`. Дополнительная установка адаптера не нужна: Codex CLI читает `AGENTS.md` от корня к текущему каталогу.

Проверено по официальному руководству OpenAI 17.11.2026: [Using agents.md](https://developers.openai.com/cookbook/examples/gpt-5/codex_prompting_guide#using-agentsmd). Доступ конкретной модели, web-поиска, квота и стоимость зависят от аккаунта; папка их не определяет. CLI-утилиты работают локально без OpenAI API.
