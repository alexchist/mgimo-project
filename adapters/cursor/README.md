# Cursor

Откройте корень репозитория как проект и начните Agent chat [запросом по задаче](../../docs/prompt-guide.md). Правило `.cursor/rules/strategist.mdc` указывает на рабочий вход `AGENTS.md`, а тот поручает прочитать `BIBLE.md`. Если правило среды не применилось, прямо попросите прочитать оба корневых файла; копировать конституцию в настройки Cursor не надо.

Формат проверен по [официальной документации Cursor Rules](https://cursor.com/docs/context/rules) 17.11.2026. Позже состоялся [текстовый разбор через Cursor Agent CLI](../../docs/grok-pilot/README.md). При [попытке продолжить запись после Codex](../../docs/field-kit/handoff/README.md) подписка вернула лимит до ответа; это не успешный тест записи, графическая IDE не проверена. Модель, web и стоимость зависят от аккаунта.
