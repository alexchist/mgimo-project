# Cursor

Откройте корень репозитория как проект и начните Agent chat [запросом по задаче](../../docs/prompt-guide.md). Правило `.cursor/rules/strategist.mdc` указывает на рабочий вход `AGENTS.md`, а тот поручает прочитать `BIBLE.md`. Если правило среды не применилось, прямо попросите прочитать оба корневых файла; копировать конституцию в настройки Cursor не надо.

Формат проверен по [официальной документации Cursor Rules](https://cursor.com/docs/context/rules) 17.11.2026. В этой поставке Cursor не был доступен в `PATH`, поэтому фактический consumer-прогон остаётся отдельной проверкой. Модель, web и стоимость зависят от аккаунта.
