# Медиа и пользовательский путь

1. Назови задачу пользователя и выбор команды, который может поменяться. Убедись, что материалы разрешены. Для синтетических файлов укажи происхождение при `prepare`.
2. Подготовь локальный медиапакет по [инструкции](../../docs/media-ux/README.md). Посмотри статусы дорожек, количество кадров и пробелы. Для видео сначала выбери кадры вокруг спорного шага. При необходимости открой оригинал и найди переход.
3. Прикрепи реальные PNG по порядку к поддерживающему изображения агенту вместе с [промптом](vision-prompt.md) и вопросом кейса. Перед загрузкой проверь доступ к данным. Укажи номер вложения и область экрана для каждой цитаты. Если зрения нет, передай человеку точный файл и вопрос. Для цитаты из аудио проверь слова и интервал на слух.
4. Зарегистрируй медиапакеты. Перенеси в `claims.csv` только сверенные наблюдения с точными адресами, например `S-001#image:1` плюс область в формулировке, `S-003#frame:5.000` или `S-004#audio:0.000-3.920`. Ответ модели помогает найти фрагмент. Основание утверждения — пиксели или звук. Реплика синтетического диктора свидетельствует только о содержании тестовой записи.
5. Свяжи вывод `C-*` с `E-*`. Укажи альтернативное объяснение и какую проверку сравнение экранов позволяет назначить. Сохрани ответ и квитанцию в `analysis/`, время, исход и стоимость в `runs/operations.csv`. Проверь кейс через `strategist.py check` и зарегистрированные медиапакеты через `media.py check --project`.
