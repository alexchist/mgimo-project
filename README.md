# Стратег Фабрики продуктов

Стратег помогает руководителю решить, что делать с продуктом и что можно обещать клиенту. Это папка для агентной среды: модель ведёт исследование, локальные инструменты проверяют числа, а основания остаются в файлах. Можно закрыть чат, принести поправку и увидеть, почему совет изменился.

## Проверить демо без ключа и без вызова модели

Скачайте или клонируйте **ветку `submission`**. Из корня, с Python 3.11 или новее:

```sh
git clone --branch submission --single-branch https://github.com/alexchist/mgimo-project.git
cd mgimo-project
python3 tools/strategist.py doctor
python3 docs/family-link/replay.py
python3 docs/field-kit/replay.py
```

Если вы распаковали архив, пропустите `git clone` и перейдите в распакованную папку. Первая проверка воспроизводит расчёт и сверяет сохранённые документы двух сеансов. Вторая проверяет материалы дополнительных опытов. Смысл совета можно оценить отдельно: откройте [записку после поправки](docs/family-link/run/after/decision-memo.md) и пройдите по ссылкам до исходной таблицы. Эти команды не генерируют новую стратегию.

## Поработать с агентом

Нужна среда с моделью, чтением и записью файлов и терминалом, например Codex. Модель использует ваш аккаунт в этой среде. Для **нового прогона демо** начните с `python3 docs/family-link/prepare.py start ../family-lab` и откройте **только `../family-lab`**, а не каталог с результатами. Дальнейшие шаги и текст для второго чата — [в инструкции](docs/family-link/demo.md).

Для своего продукта откройте корень репозитория. Агент может сам создать дело; вручную это `python3 tools/strategist.py init projects/my-case --slug my-case --title "Мой продуктовый вопрос"`. Укажите папку с разрешёнными материалами и напишите:

> Начни дело `projects/my-case`. Нужно решить, стоит ли менять продукт. Уточни, чей это выбор, прочитай мои материалы и подготовь варианты, обе стратегии и записку к встрече. Назови, какой факт изменит твой совет. Не принимай решение за меня.

Для продолжения: «Открой `projects/my-case`. Где мы остановились и что сегодня требует моего решения?» Агент читает `state.md` и реестры через `resume`; для исправления существенного основания сначала сохраняет прежнюю версию через `revise`.

**Зависимости и данные.** Основной CLI использует стандартную библиотеку Python; для PDF с текстовым слоем нужен `pdftotext` из Poppler. Семейное демо не требует Poppler. [Изображения, звук, модельные интервью, MCP и хуки](docs/field-kit/README.md) — отдельные возможности со своими зависимостями, не условия первого запуска. Работа в облачной IDE может передавать прочитанное её провайдеру: используйте только материалы, на которые у вас есть разрешение. В архиве нет исходного PDF организатора, приватной памяти или ключей. [Границы инструментов](docs/limitations.md) · [Сторонние материалы и права](THIRD_PARTY_NOTICES.md).

**Для самостоятельной проверки:** `python3 -m unittest discover -s tools/tests -v`. [Справочник CLI](tools/README.md) · [Другие учебные задачи](evals/cases/) · [Проверенные случаи пользы и контрпримеры](docs/folder-evidence.md).

Ветка содержит конкурсную версию. Полная история экспериментов и прежние редакции сохранены в `main`. Для подачи капитан сверяет бриф в личном кабинете и даёт ссылку на видео с площадки из задания; MP4 в этой папке — исходный файл для загрузки.
