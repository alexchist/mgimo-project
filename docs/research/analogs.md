# Аналоги и готовые решения

Это decision-oriented desk research, не рейтинг качества. Hands-on выполнен только с исходными инструкциями Spec Kit; остальные строки из первичной разведки мастер-плана и требуют новой проверки перед покупкой/интеграцией.

| Аналог | Полезный паттерн | Не покрывает / риск | Решение |
|---|---|---|---|
| OpenAI Deep Research / Perplexity Research | план, поиск, цитированный отчёт | переносимая история решения/обязательств; account/cost | внешний baseline при доступе, не dependency |
| Dovetail / EnjoyHQ | signal→source, research repository | полный strategic choice и portability; SaaS | не брать в core |
| Productboard | feedback→opportunity→roadmap | коммуникационная стратегия и evidence correction; SaaS | не брать в core |
| GPT Researcher | web/local research pipeline | стратегическая логика и post-decision | опциональный benchmark |
| STORM / Co-STORM | вопросы с разных перспектив, citations | research article focus | идеи для critic, без integration |
| Spec Kit assess | gaps, evidence against, honest kill, safe file path | five user stages; ends before strategy/follow-through | фактически сравнили; borrow ideas |
| BMAD | packaged roles/templates | context/role overhead | не брать без measured benefit |
| Agent Skills format | progressive procedure folders | cross-IDE behavior not identical | простые SKILL.md used |
| MarkItDown / Docling | broad document conversion | dependencies/OCR and locator validation | stdlib+pdftotext first; revisit for hard docs |

Критерий добавления: исправляет измеренный класс ошибок, существенно экономит время или даёт формат, который core не читает, при известной полной стоимости.
