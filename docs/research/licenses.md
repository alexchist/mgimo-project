# Лицензии и зависимости

## Включённое авторское ядро

`AGENTS.md`, skills, CLI, templates, synthetic fixtures и документация написаны для этого проекта; код Ouroboros и личная память не копировались. Лицензия владельцем пока не выбрана. Не добавлять permissive LICENSE автоматически, особенно до решения по условиям submission.

## Стороннее, не включённое как код

- GitHub Spec Kit commit `e210504aa09c9273a38bba665b12b8088468c96f`, MIT: прочитан и сравнён; файлы/существенный текст не скопированы. Идеи process не требуют переноса license notice, но ссылка и commit сохранены.
- Python 3 standard library: runtime dependency, не vendored.
- Poppler `pdftotext`: внешний optional-by-format executable, не vendored; его лицензия и установка остаются у дистрибутива пользователя.
- Cursor/Codex: внешние среды по условиям аккаунта; не зависимости Python и не распространяются.
- Методические страницы и статьи: ссылки/краткое изложение, полные тексты не копируются.
- Example Domain snapshot в `examples/web-smoke`: сохранён как проверочный web-источник с origin/hash, а не как часть авторского метода.

Перед архивом проверить, что сторонние материалы в demo допускают сохранение/распространение; для web можно оставить URL+короткий extract вместо полного snapshot, если права неясны.
