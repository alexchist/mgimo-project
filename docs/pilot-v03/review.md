## Критические границы, оставленные честно

Одностраничность — редакционный ориентир, не гарантированный размер печатного листа. `check` не доказывает смысловую поддержку цитаты, актуальность всех абзацев или качество стратегии. Полные страницы авторов не распространяются в репозитории: сохраняем URL, объём чтения и собственную адаптацию; точные tool-source записи остаются в задаче. Перечитывать/архивировать полные чужие книги ради доказательства не требуется.

Новые прогоны оцениваются отдельно от критики ядра. Ни формальные тесты, ни перечень книг не дают основания заявлять превосходство над сильным обычным чатом.

## Поздняя проверка snapshot-fix

Отдельный read-only Codex medium `run-cf67a842256a` подтвердил порядок snapshots перед реестрами, byte fidelity, schema и Markdown. Отметил два ограничения: hashes снимков после завершения не проверяются; после жёсткого прерывания временный файл мог блокировать rollback/retry. Второе исправлено: отказ касается совпадающих имён сохраняемых документов, не произвольного неучтённого временного файла; регрессия сохраняет такой файл и успешно повторяет revise. Первое оставлено явной границей: папка не защищает историю от ручного изменения/удаления, check не обещает этого. Нет основания строить отдельное tamper-proof хранилище ради текущего локального сценария.

Критик также назвал предсуществующий отказ ingest при повреждённом не-array индексе (возможен AttributeError до failure log). Это отдельный открытый дефект, не замаскирован исправлением snapshots; при повреждённом индексе сначала check и восстановление из сохранённой копии. Панельного PASS этим проверкам не приписываем.
