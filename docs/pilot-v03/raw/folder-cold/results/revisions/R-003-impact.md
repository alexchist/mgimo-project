# Карта влияния исправления S-005

## Что изменилось

- Источник `S-005#line:2` полностью заменил переменную стоимость `paid_pilot` с 1500 на 4800 RUB/аккаунт-месяц; остальные входы не изменились. Старое основание `E-012` сменило статус на `superseded`; актуальное — `E-019` (`R-001`).
- Прежний расчёт `E-015`: +165000 RUB при 30 аккаунтах и безубыточность с 18. Актуальный `E-020`: −132000 RUB при 30 и безубыточность с 67 (`R-002`).
- Прежний вывод `E-016`: `paid_pilot` обгоняет `manual_service` с 22 целых аккаунтов. Актуальный `E-021`: при равном неотрицательном числе аккаунтов не обгоняет никогда, потому что и маржа ниже, и фиксированные затраты выше (`R-003`).
- Пересмотрены `C-004`–`C-006`. Рекомендация O-2 сохранилась и усилилась; ближайшая реалистичная альтернатива сменилась с O-3 на O-1.
- O-3 больше не имеет порога переключения только по числу аккаунтов. При 30 аккаунтах неполная модель даёт порог цены 7466.67 RUB для безубыточности и 8433.33 RUB для равенства с `manual_service` того же объёма. Это чувствительность, а не рекомендация цены.
