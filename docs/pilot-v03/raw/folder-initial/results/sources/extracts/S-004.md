# Извлечение S-004

Ручное построчное извлечение из Markdown; свёрено с оригиналом. Это не интерпретация.

## Фрагменты

- `line:1` — Заметки о трёх ознакомительных разговорах; данные синтетические.
- `line:2` — Один администратор в недавнем эпизоде собрал 43 уведомления из трёх файлов за 50 минут; цена, договор и покупка не обсуждались.
- `line:3` — Руководитель выразил условный интерес при отсутствии поломки процесса; покупку не обещал.
- `line:4` — Другой администратор использует таблицу и проблемы не сообщил; выборка из знакомых команды нерепрезентативна.
- `line:5` — Слайд продаж называет 30 аккаунтов подтверждённым спросом и обещает мгновенность и любую МИС; иных оснований, кроме разговоров, нет.

## Пробелы и ограничения

- Markdown не поддержан штатным `ingest`; сохранена побайтовая копия, SHA-256 и проверяемые строки.
