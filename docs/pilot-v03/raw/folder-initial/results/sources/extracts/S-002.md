# Извлечение S-002

Ручное построчное извлечение из Markdown; свёрено с оригиналом. Это не интерпретация.

## Фрагменты

- `line:1` — Учебный кейс «Тихий час».
- `line:2` — Все организации, люди и цифры вымышлены; это вход для проверки, не данные МегаФона.
- `line:3` — Дата решения 17.11.2026; требуется решить, запускать ли платный пилот на 3 месяца; бизнес-решение и ответственные не подтверждены; внешние действия не нужны.

## Пробелы и ограничения

- Markdown не поддержан штатным `ingest`; сохранена побайтовая копия, SHA-256 и проверяемые строки.
