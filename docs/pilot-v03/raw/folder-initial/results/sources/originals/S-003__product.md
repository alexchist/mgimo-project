# Возможности и ограничения — продуктовая команда, 16.11.2026
Продукт собирает уведомления в одну ежедневную сводку. Реального времени нет. Сервис не принимает медицинские решения; медицинские данные нельзя загружать. Сейчас доступен только CSV импорт обезличенных событий. Интеграция с МИС не реализована. Безопасный ручной процесс существует и не требует новой разработки.
Есть один инженер на 10 рабочих дней до пилота; после этого 2 дня в месяц на поддержку. Дизайн/продажи не выделены. Это сведения о доступной ёмкости, не принятие обязательств конкретным человеком. Три месяца пилота считаются календарными месяцами после старта, заранее выбранной даты старта нет.
