## Ограничения/ошибки

- Markdown не поддержан `ingest`: IF-001/IF-002. Оригиналы не менялись; импортированы побайтно точные `.txt`-копии, хэши совпали. OP-001 ошибочно завершена как успешная групповая операция; OP-002 и IF-001/IF-002 append-only корректируют фактическую картину.
- Ожидаемые warning: extraction gaps для plain text; `review_needed=yes` для рекомендации; `unknown` стоимость LLM; два failed ingest attempts.
- Нет валидной retention-динамики, реального спроса, экономики, команды, бюджета, срока или назначенного владельца. Поэтому рекомендация условна, а решение не принято.
