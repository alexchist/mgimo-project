# Медиа и UX-разбор

На каком шаге отправитель видит, сколько спишется за семейный перевод? В учебном примере есть два [собственных экрана](fixtures/family.html#1), [десятисекундное видео](fixtures/family-walkthrough.mp4) и [русская звуковая дорожка](fixtures/family-voice.wav). PNG сняты с локального макета. Речь сгенерирована eSpeak NG из вымышленных фраз. [Английская запись](fixtures/family-voice-en.wav) сгенерирована Flite для второй проверки распознавания. Клиентских данных в примере нет.

## Начать без сети

Нужен Python 3.10+. Для PNG и JPEG этого достаточно. Команды из корня репозитория создают новый учебный кейс.

```sh
case_dir=projects/family-transfer
fixtures=docs/media-ux/fixtures
python3 tools/media.py doctor
python3 tools/strategist.py init "$case_dir" --slug family-transfer --title "Семейный перевод"
for step in 1 2; do
  bundle="$case_dir/sources/media/step-$step"
  python3 tools/media.py prepare "$fixtures/family-step-$step.png" --origin synthetic --output "$bundle"
  python3 tools/media.py ingest "$case_dir" "$bundle"
done
```

`prepare` сохраняет исходные байты и опись с SHA-256, размерами и статусами. Чтобы продолжить кейс в другом редакторе, перенесите всю его папку. `ingest` добавляет в обычный реестр копию оригинала, извлечение с адресами и ссылку на опись пакета. `strategist.py check` сверяет реестр и ссылки. Для проверки производных кадров, WAV и JSON нужна дополнительная команда.

```sh
python3 tools/media.py check "$case_dir/sources/media/step-1" --project "$case_dir"
python3 tools/strategist.py check "$case_dir"
```

## Передать пиксели модели

**Редактор с поддержкой изображений.** Прикрепите оба `original.png` как изображения в порядке шагов, вставьте [промпт UX-разбора](../../skills/media-ux/vision-prompt.md) и укажите, что вложения соответствуют `S-001#image:1` и `S-002#image:1`. Открыть путь в текстовом контексте недостаточно. Если модель не видит вложения, откройте файлы сами и сохраните проверенные наблюдения.

**Codex CLI.** Нужны `codex` в `PATH`, вход в аккаунт и доступ к модели с обработкой изображений. Команда передаёт файлы через `codex exec --image`. Она требует явный `--allow-upload`, работает из временной папки и сохраняет ответ и квитанцию.

```sh
python3 tools/media_vision.py "$case_dir/sources/media/step-1" "$case_dir/sources/media/step-2" \
  --allow-upload --output "$case_dir/analysis/ux-01" \
  --question "В какой момент получатель и итоговая сумма понятны отправителю?"
```

Добавьте `--model` с доступной вам моделью или используйте модель Codex по умолчанию. Квитанция фиксирует SHA-256 вложений, время, запрошенную модель и счётчики токенов при наличии. Статус `response_saved` означает, что ответ сохранён. Сверьте цитаты по пикселям и укажите область экрана. Настройка тарифа и правила хранения данных зависят от провайдера. В запрос уходят целые изображения с возможными метаданными и ваш вопрос. Используйте материалы, разрешённые к передаче данной модели. При `started` после прерывания или `outcome_unknown` сверьте квоту и результат перед новым вызовом. Если Codex отсутствует, квитанция получает `unavailable`.

**Пример вывода.** `C-001` — проверить ранний показ полной суммы. `E-001` — в карточке первого шага указано «Сумма перевода 300 ₽», а ниже виден баланс 520 ₽, `S-001#image:1`. `E-002` — на втором экране в карточке указано «Комиссия 25 ₽» и «Спишется 325 ₽», `S-002#image:1`. Гипотеза — отправитель может принять 300 ₽ за полное списание. Другая версия — «Далее» даёт понять, что окончательные условия появятся на проверке. Сравните текущий прототип с ранним показом комиссии. До кнопки «Далее» измерьте долю участников, ожидающих списания ровно 300 ₽, и заранее назначьте порог, при котором стоит менять экран. Сами скриншоты устанавливают порядок раскрытия суммы. Ответ о поведении требует проверки на людях.

## Видео и речь

Для записей нужны `ffmpeg` и `ffprobe` в `PATH`. Без модели команда извлекает кадры и WAV, а в описи получаете `transcript: not_requested`.

```sh
bundle="$case_dir/sources/media/walkthrough"
python3 tools/media.py prepare "$fixtures/family-walkthrough.mp4" --origin synthetic --output "$bundle"
python3 tools/media.py ingest "$case_dir" "$bundle"
python3 tools/media.py check "$bundle" --project "$case_dir"
```

У каждого PNG есть время кадра из FFmpeg. В примере сохраняются `frame:0.000`, `frame:2.500`, `frame:5.000`, `frame:7.500`. У дорожки отдельный `audio:track`. Время отсчитывается от начала контейнера. Звуковая дорожка приведена к моно WAV 16 кГц, в начале добавляется тишина при задержке старта. Для визуального разбора приложите несколько PNG в порядке времени или укажите пакет видео в `media_vision.py`. В этом вызове передаются только кадры. Проверьте важные действия между ними в оригинальном видео. [Параметры фильтров FFmpeg](https://ffmpeg.org/ffmpeg-filters.html).

Для офлайн-распознавания установите [whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/v1.7.6) с `whisper-cli` в `PATH` и скачайте [локальные веса](https://huggingface.co/ggerganov/whisper.cpp/tree/main) отдельно. Проверена версия 1.7.6. Достаточно одной модели, например Tiny (77,7 МБ) или Base (148 МБ). Выберите мультиязычный файл для русского. После установки сеть не нужна. Код не скачивает модель и не обращается к сервису расшифровки.

```sh
bundle="$case_dir/sources/media/voice"
python3 tools/media.py prepare "$fixtures/family-voice.wav" --origin synthetic --output "$bundle" \
  --whisper-model /path/to/ggml-tiny.bin --language ru
python3 tools/media.py ingest "$case_dir" "$bundle"
```

Тот же флаг работает для видео. `audio:0.000-3.920` ссылается на интервал в отдельном WAV. В `whisper.json` остаются сегменты и оценки времени движка, путь к весам сокращён до имени файла. Если движок поставил конец сегмента за пределами WAV, в адресе указан конец дорожки, а исходная оценка остаётся в `model_end_ms`. Сверяйте текст и границы на слух перед цитированием. Tiny и Base сильно исказили русские синтетические фразы в этом примере. Такие результаты годятся для диагностики распознавания. Цитировать эти фразы можно после прослушивания.

## Пределы и стоимость

- Изображения PNG и JPEG до 25 МиБ, проверка сигнатуры и исходных байтов. Видео MP4, MOV, WebM, MKV и аудио WAV, MP3, M4A, OGG, FLAC до 120 секунд и 100 МиБ при наличии нужного декодера. Для видео берётся первая обычная видеодорожка и первая звуковая. `--frames` задаёт максимум от 1 до 12. Короткие или редкие события могут пропасть между кадрами. Для запроса Codex действует общий максимум 12 файлов и 25 МиБ.
- У частичного пакета сохраняется оригинал и статус `unavailable` или `failed` с причиной. Выход `2` требует прочитать опись. `no_stream` означает отсутствие дорожки, `no_segments` — отсутствие возвращённых отрезков речи. Для новых производных используйте новый каталог. После оборванного импорта следуйте `strategist.py check` и `ingest-recover`. С файлом кейса работает один автор.
- Локальные операции расходуют процессорное время и место. Видео может занимать место и в медиапакете, и в `sources/originals/`. Облачное зрение расходует квоту аккаунта и время на сверку. Тариф по счётчику токенов команда не вычисляет. Запишите это вместе со временем проверки и итогом в `runs/operations.csv`.
- Исходники, WAV, цитаты и ответы могут содержать персональные данные. Храните и передавайте только разрешённые материалы. Изображения и реплики разбираются как данные. Текст с них не даёт полномочий выполнять команды.
