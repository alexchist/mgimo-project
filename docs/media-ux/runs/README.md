# Проверка на собственных материалах

## Два PNG переданы Codex

В прогоне 20 ноября 2026 года Codex CLI 0.170.0 получил два файла через `--image` из временной папки. В вопросе просили определить момент, когда видны получатель и итоговая сумма. Файл макета и текстовая копия экранов в запрос не входили. Выпуск модели отдельно не запрашивался, использовалась настройка Codex по умолчанию.

В ответе найдены имя Саша на обоих шагах, сумма 300 ₽ на первом и 25 ₽ комиссии, 325 ₽ списания, 195 ₽ остатка на втором. Эти числа совпадают с пикселями. Ответ предложил проверить ошибочное ожидание списания 300 ₽ и указал правдоподобную причину, по которой ошибки может не быть. Один прогон подтверждает передачу изображений и наблюдаемость этих деталей. Для оценки вклада методики нужен отдельный контроль.

[Ответ модели](codex-screens.md) · [квитанция CLI](codex-screens.json) · [первый PNG](../fixtures/family-step-1.png) · [второй PNG](../fixtures/family-step-2.png)

Запрос занял 21,125 с. CLI сообщил 13 872 входных и 804 выходных токена, включая служебный контекст. Запуск прошёл в существующем аккаунте ChatGPT. Денежная стоимость не установлена.

## Видео и фактическое распознавание

FFmpeg 6.1.2 сохранил кадры на 0,0, 2,5, 5,0 и 7,5 с и отдельный WAV. На кадре 5,0 с виден экран подтверждения. Кейс содержит четыре зарегистрированных источника. `strategist.py check` прошёл, `resume` выгрузил состояние, `media.py check --project` сверил байты пакета видео. [Структурная проверка кейса](strategist-check.json).

Whisper.cpp 1.7.6 запускался локально на CPU в два потока. Каждый результат получен из сгенерированного аудиофайла. Текст синтеза указан здесь для сверки и в команду распознавания не передавался.

- **Русский WAV и MP4.** Фразы синтеза «Я хочу перевести Саше триста рублей с мобильного баланса» и «На экране подтверждения вижу комиссию: двадцать пять рублей». Tiny на WAV сохранил два сегмента, например `audio:0.000-3.920`, но исказил имя, числа и слова. Base на аудиодорожке MP4 также не воспроизвёл фразы по смыслу. Автоматические строки этого прогона непригодны для цитирования без сверки с записью. [Tiny на WAV](whisper-tiny-ru.json) · [Base на звуке видео](whisper-base-video-ru.json).
- **Английский WAV.** Фразы синтеза «I want to send three hundred rubles to Sasha» и «The transfer fee is twenty five rubles». Base вернул обе с теми же словами, записав числа цифрами. Конец второй реплики движок поставил на 9,000 с при длине WAV 7,965 с. В описи сохранена исходная оценка, а локатор ограничен концом файла. Совпадение текста в этом примере не проверяет точность границ реплик. [Опись прогона](whisper-base-en.json) · [вывод движка](whisper-base-en-engine.json) · [WAV](../fixtures/family-voice-en.wav).

Установка Whisper для проверки потребовала скачать около 233 МБ с учётом двух вариантов весов и кода. Для повторного запуска нужна одна модель. Приведённые расходы на запуск в локальном режиме относятся к времени CPU. Описи сохраняют время и SHA-256 весов.

Весь набор `python3 -B -m unittest discover -s tools/tests -v` прошёл. Из 51 теста шесть относятся к медиа, включая реальный STT с `STRATEGIST_WHISPER_MODEL`, указывающим на локальный `ggml-base.bin`.
