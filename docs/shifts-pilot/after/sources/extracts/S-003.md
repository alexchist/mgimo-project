# Извлечение S-003

Автоматическое извлечение; это не интерпретация и не подтверждение истинности.

## Фрагменты

- `title[1]` — Сменная книга — учебный каталог
- `h1[1]` — Возможности для администратора
- `p[1]` — Сервис собирает график из загруженного CSV и позволяет скачать его в PDF. При недостающих полях администратор дополняет шаблон вручную.
- `p[2]` — Обмена графиком с кассой нет. Команда изучает спрос, не объявляла дату такой интеграции и не предлагает записаться в очередь.

## Пробелы и ограничения

- Извлечён только статический HTML-текст: JavaScript-rendered content, CSS visibility, canvas, media and linked pages не интерпретированы.
