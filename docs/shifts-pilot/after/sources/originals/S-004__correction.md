# Поправка к предложению «Сменная книга» (учебный источник)

Подтверждение продуктовой команды после первого отчёта: выгрузка графика в PDF была опцией прототипа, в действующем продукте её нет. Можно составить график из загруженного CSV и посмотреть его в кабинете. Таблицу удержания не пересчитывали; определение активности не менялось. Разрешения связываться с магазинами или запускать тест нет.
