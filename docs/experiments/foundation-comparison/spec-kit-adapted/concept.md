# Concept: status freshness

## Options

### A — измерить текущий процесс

- Appetite: small.
- За 2 недели посчитать своевременность статусов, время встречи и причины трёх запросов без бота.
- Trade-off: меньше скорости решения, зато не требует автоматизации неизвестной проблемы.

### B — ограниченный ручной пилот напоминаний

- Appetite: small, но стоимость не оценена.
- Вручную отправлять согласившимся участникам напоминания и сравнить своевременность/раздражение с baseline.
- Trade-off: ближе к механизму, но эффект канала и ручной работы смешан.

### C — не продолжать

- Appetite: none.
- Сохранить процесс; вернуться при измеримом ущербе.

## Recommendation

Сначала A. Оснований для автоматизированного пилота недостаточно.
