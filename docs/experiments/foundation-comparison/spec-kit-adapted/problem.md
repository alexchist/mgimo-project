# Problem Definition: stale project statuses

## Problem statement

Часть команды может не обновлять статусы вовремя, но частота и последствия не установлены. Сейчас нельзя подтвердить, что проблема стоит автоматизации.

## Users and stakeholders

- Users: 8 участников команды; различия их ситуаций неизвестны.
- Stakeholder: руководитель, предлагающий пилот; бюджетные полномочия неизвестны.

## Goals and success metrics

- Уменьшить долю просроченных обновлений без роста раздражения; baseline и порог неизвестны.

## Non-goals

- Не заменять систему управления проектами и не делать вывод о других командах.

## Cost of inaction

Неизвестна; текущие таблица и встреча продолжаются.
