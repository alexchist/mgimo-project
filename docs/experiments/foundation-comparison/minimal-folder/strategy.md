# Черновик согласованных стратегий

## Продукт

Пока не строить бота. Для команды из 8 человек установить baseline: доля статусов, обновлённых к согласованному сроку, минуты встречи на восстановление контекста и число нежелательных напоминаний. Направление рассматривается только при явном ущербе и добровольном канале. Отказ: не заявлять масштабирование на другие команды.

## Коммуникация

Не обещать «автоматически актуальные статусы». При ручном тесте сообщение: «Напоминание помогает не забыть обновление; участие можно прекратить». Подтверждение пользы отсутствует; формулировка только про назначение теста.

## Проверка

Сначала 2 недели baseline. Затем, если человек одобрит, сравнить с 2 неделями ручных напоминаний среди согласившихся. Primary metric: доля обновлений к сроку (числитель/все ожидаемые обновления). Guardrails: отказы, жалобы, ручные минуты. Минимально полезный эффект и достаточность данных неизвестны; при 8 участниках не заявлять статистическую доказанность.
