# Передача дела: Codex → другая среда

Новая среда видела [сохранённый первым Codex кейс](../../family-link/run/before/), обычные правила папки и [два новых источника](../../../evals/cases/family-link/update/), но не его диалог, готовую вторую записку или конкурсный PDF. Это продолжение сохранённой работы, не новый запуск первого этапа.

| Получатель | Что произошло | Что проверили по файлам |
|---|---|---|
| Cursor Agent CLI, Linux | На `--print --sandbox enabled` CLI показал init, затем `You've hit your usage limit`. За 10,48 с финального ответа не было. | Кейс после отказа побайтно совпал с переданным. Другую модель за Cursor не засчитываем. |
| Claude Code, первый новый чат | Импортировал два материала, выполнил `revise`, сохранил историю. Запросил право запустить написанный им скрипт для оценки мощности. В нашей среде такого разрешения не было. [Ответ](claude.md). | При выходе 0 записка оставалась прежней: это **частичный** результат, не успешное завершение. |
| Claude Code, ещё один новый чат | Передали копию частично завершённой папки и уточнили: «расчёт мощности не нужен, не запускай новые скрипты». Нашёл сделанный импорт и ревизию, исправил вывод и записку без второго импорта. [Ответ](finish.md) · [записка](case/decision-memo.md) · [обе стратегии](case/strategy.md). | Одна ревизия; пять прежних документов совпали с первым Codex побайтно; 5 исходников, текущие рекомендации изменены, решения не записаны. Сохранённая папка прошла `check` и `resume`. |

Архивы сохраняют исходные Markdown-файлы побайтно, включая прежние относительные ссылки. Чтобы пройти по ним на GitHub, откройте [записку в первоначальном кейсе](../../family-link/run/before/decision-memo.md), а не её копию во вложенном каталоге ревизии.

**Содержательная проверка.** Четыре строки — это 400 разных подходящих семей, а не 620 событий с повторами. Прогноз при прежнем темпе: около 900 за девять недель против цели 3 600. Тест в таком виде не успевает; отсутствие эффекта из подсчёта не следует. В записке осталась лишняя уверенность, что полная цена теста выросла: из потока прямо следует рост срока набора, но не сумма затрат. Сохранённый текст не правили для выставления оценки. Строка OP-002 содержит условное время, проставленное моделью, а не измерение: для времени и цены используйте `runs.json`, не эту строку.

Два процесса Claude заняли 64,32 и 121,67 с; CLI сообщил модель `claude-sonnet-5-5` и оценки по прейскуранту около $0,25 и $0,42. Это не счета за подписку; помощь координатора была, минуты человека не измерены. Скрипт `case/analysis/shadow.py` оставлен как материал первого чата, не как утверждённый расчёт мощности. [Машинные наблюдения](runs.json). Графические IDE, другая ОС и реальная работа продакт-менеджера не проверялись.

**Повторить:** из чистой копии выполните первый шаг [демо](../../family-link/demo.md) в Codex; закройте чат, перенесите **папку целиком**, добавьте материалы командой `update`. Новую папку откройте в Cursor Agent или Claude Code: «Прочитай корневой AGENTS.md и выполни update-request.txt; не принимай решений за меня». Аккаунт и право читать/писать в этой папке нужны у второй среды. Давайте разрешения на конкретные проверенные операции; для завершения не нужно разрешать запуск любого сгенерированного кода. Для офлайн-проверки готовой передачи: `python3 tools/strategist.py resume docs/field-kit/handoff/case`.
