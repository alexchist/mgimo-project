# Состояние кейса

## Cold resume

- Вопрос решения — стоит ли выделить до 20 000 ₽ на разбор причин и наблюдение без отправки сообщений, чтобы проверить возможность своевременной ручной помощи.
- Совет агента — проверить предпосылки предупреждения для организатора общей группы на одном совместимом тарифе. Выбор человека pending.
- Основания — [C-001–C-004](evidence/conclusions.csv) → [E-001–E-010 с точными адресами](evidence/claims.csv) → [S-001–S-003](sources/index.json).
- Критичное допущение — ранний сигнал иногда оставляет достаточно времени и свободного объёма. Если допустимые данные это не подтверждают или проверка не различает причины, предпочтительно обычное обслуживание.
- Последний подтверждённый шаг — импорт трёх учебных источников, сверка извлечений, пересчёт дизайна и сборка материалов для планёрки в OP-001.
- Следующий ход — обсудить один лимит из записки. При согласии подтвердить допустимые данные, объём работ и роль исполнителя. Будущий клиентский тест требует отдельного решения.
- Для нового чата — прочитать корневой BIBLE.md и запустить `python3 tools/strategist.py resume projects/family` из корня, затем открыть записку и проверить основания в реестрах.
