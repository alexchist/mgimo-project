# Учебное уточнение: четыре недели наблюдения без сообщений

В shadow.csv — вымышленные итоги теневого подсчёта. Семья попадает в колонку новых один раз за все четыре недели; в колонке событий возможны повторы. Правило отбора и тариф те же, что в плане. Ни одна семья не получала предупреждение. Наблюдение ничего не говорит о том, снижает ли оно число перебоев. Расходы на следующий этап не утверждали.
