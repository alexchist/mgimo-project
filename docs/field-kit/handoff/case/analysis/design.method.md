# Проверка учебного плана набора

- Вход — [S-003](../sources/originals/S-003__design.csv), SHA-256 `00a5dbae0def9f41dc87ba9fb0964a93f47193cf3520d57cff9515c6e76fac87` (см. индекс для контрольного значения).
- В оригинале и извлечении совпали шесть параметров, статусы, единицы и описания. CSV разделён запятыми, пропусков и дублей параметров нет. Каждая строка — параметр плана. Данных на семью или по неделям в таблице нет. Для S-001 и S-002 сверены все четыре непустые строки каждого оригинала с извлечениями.
- Из корня репозитория: `python3 projects/family/analysis/design.py`. [Выход](design.txt).
- Строки 2–4 дают число недель, общую цель и прогноз первых подходящих семей. Чувствительность ±10% к прогнозу иллюстративная. Цель достижима при среднем потоке 400 назначаемых семей в неделю. Если 400 — только входящий поток до согласий и иных исключений, любое дальнейшее отсечение при том же потоке приведёт к недобору. Неделя созревания в набор не входит. Запас на пропуски уже заложен в общей цели, его размер неизвестен.
- Строки 5–6 дают сценарные частоты за семь суток среди назначенных семей. Разность 3 п. п. и относительное снижение 25% описывают альтернативную гипотезу. Для проверки мощности нужны согласованный полезный эффект, фактическая база, правило анализа и оценка полноты исходов. Цель 3600 сама по себе достаточность не подтверждает.
- Строка 7 — предложение потолка прямых расходов. Данных о разработке, сопровождении, доходе и экономии на предотвращённом ограничении для расчёта окупаемости нет.
