# Поставщик заменил таблицу. Какие строки записки перечитать?

В кейсе хранится снимок, а не живая ссылка на диск поставщика. В отдельном терминале можно включить локальный хук на один исходный файл. Он сравнивает его байты с отпечатком, записанным при импорте. При изменении или исчезновении файла выводит связанные утверждения, выводы, решения, обязательства и номера строк в текущих документах. Содержимое никуда не отправляется. Код не считает совет ошибочным и не изменяет принятое решение.

**Попробовать** (из корня, Linux/macOS; пример с копией, архив не редактируем):

```sh
lab=$(mktemp -d)
cp evals/cases/family-link/start/design.csv "$lab/design.csv"
python3 tools/source_watch.py docs/family-link/run/before S-003 "$lab/design.csv" --until-change
```

Сначала появляется `matches_import`. Измените прогноз набора в **своей копии** файла и сохраните. Появится `changed`; в `review.document_lines` — например, строка записки, где требуемые 3 600 семей поставлены в зависимость от потока. Если файл исчезнет, событие — `missing`, а не нулевой поток. Без `--until-change` проверка продолжается до Ctrl+C; `--once` годится для однократного запуска из собственного обработчика события в IDE. Хук видит разницу между опросами, а не каждую промежуточную запись. По умолчанию раз в две секунды он перечитывает один файл; не выбирайте большой ролик без увеличения интервала.

Пара `ID → внешний файл` задаётся явно. Хук не ищет файлы на компьютере, не наблюдает закрытый проект сам собой и не умеет вывести неуказанную смысловую зависимость из текста. Старый источник и решения остаются неизменными. Если новое значение действительно меняет основание, ведущий импортирует поправку как отдельный источник и вызывает `revise` до редактуры. После перехода на новую версию источника запустите хук с её ID. Для Windows используйте свой временный каталог и `py -3` вместо `python3`.

**Без второго терминала, в Claude Code.** Для подготовленного [семейного демо](../family-link/demo.md) возьмите [пример настройки](../../adapters/claude/source-hook.example.json). Из корня `family-lab` передайте файл флагом `claude --settings /путь/к/source-hook.example.json`. Команда хука привязана именно к паре `projects/family S-003 materials/start/design.csv`; в своём кейсе замените все три аргумента после проверки ID источника. Для PowerShell/Windows нужен эквивалент команды для используемой оболочки. В профиль настройки сами не устанавливаются. [Протокол Claude Code](https://code.claude.com/docs/en/hooks): `PostToolUse` после `Edit`/`Write`, ответ в `additionalContext`. Правка внешним редактором или командой Bash такого события не вызывает; для неё используйте наблюдатель.

В отдельном настоящем сеансе Claude Code на копии семейного демо заменили 400 на 350 в `weekly_flow`. Получили [ответ хука](hook-result.json): проверить C-002, C-004 и, в частности, строку 16 `decision-memo.md`; модель передала это в ответе, записка осталась побайтно прежней. Хук определяет связи всего изменившегося источника, не утверждает, что каждое связанное число стало ложным.
