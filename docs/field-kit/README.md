# Что ещё можно поручить Стратегу

**Начните с двух [экранов семейного тарифа](data-share/README.md).** На первом родитель выбирает 3 ГБ из доступных 12, на втором видит «Детский планшет», но уже не видит объём. Агенту передали два PNG. Он предложил вернуть выбранное число на экран подтверждения. Это разница между советом, который можно проверить сразу, и гипотезой «люди ошибаются», для которой нужен отдельный тест.

[Короткий разбор со снимками в PDF](field-notes.pdf) · [Демо основного процесса в двух чатах](../family-link/demo.md).

| Что нужно руководителю | Как попробовать и что получилось |
|---|---|
| Проверить текст или путь на экране | [Промпт, два макета и полный ответ](data-share/README.md). На отдельной [паре про перевод рублей](ux-protocol.md) оба чата верно прочли комиссию; с промптом появился измеримый тест, обычный чат ответил быстрее. |
| Разобрать запись | [Команды и учебные файлы](../media-ux/README.md). Из десяти секунд видео извлекли четыре кадра с отметками времени и отдельную звуковую дорожку. [Распознавание речи](../media-ux/runs/README.md) сохранило смысл английской записи, но исказило имя и числа в русской. Перед цитированием откройте нужный фрагмент оригинала. |
| Подготовить интервью | [Четыре реплики респондента и отдельная критика](../advisors/family-tariff/README.md). Ведущий уточнял, как участник мог восстановить интернет без организатора. Получился вопрос для проверки: **успела бы помощь семьи раньше самостоятельного пополнения?** Синтетический диалог не подтверждает ни одного случая у реальных абонентов. Для настоящего интервью есть [гайд по согласию и разбору](../../skills/interview/guide.md). |
| Решить, когда нужна ещё одна модель | [Выбор маршрута и профиль ролей](../advisors/README.md). Таблицу считает локальная команда; респондент и критик получают разные пакеты текста, модели и уровни усилия. Видно, какой маршрут запрошен и какой подтвердил CLI. Отказ не тратит квоту на скрытый повтор. |
| Узнать, где правка исходника затрагивает записку | [Пример хука](source-hook.md). После изменения прогноза потока Claude Code получил ссылки на C-002, C-004 и строки документов. Решение и текст он не менял. Вне Claude можно явно включить наблюдение за одним файлом на время работы. |
| Найти похожее решение своими словами | [Локальный поиск и примеры](../mcp-recall/README.md). Запрос про `churn после промо` находит урок про отток и состав каналов. Рядом видны источник и его состояние; отозванная карточка доступна только как история. Это словарные связи на русском и английском, не универсальная модель смысла. |
| Открыть кейс через MCP в своей IDE | [Пример подключения](../../adapters/mcp/README.md). Четыре операции: найти прецедент, искать в реестрах выбранного кейса, восстановить состояние, проверить целостность. Запись решений через MCP не разрешена. Обмен проверен официальным SDK, не графическим Cursor. |
| Продолжить в другой среде | [Codex → Claude Code: что осталось на диске](handoff/README.md). После одного уточнения Claude обновил обе стратегии, сохранил пять документов и не записал согласия руководителя. Cursor CLI в этой попытке достиг лимита до ответа; это не проверка графического Cursor. |

**Проверка без модельного аккаунта.** Из корня запустите `python3 docs/field-kit/replay.py` и `python3 docs/family-link/replay.py`: они сверяют сохранённые материалы, числа семейного кейса и историю правок. Это повторная проверка файлов, а не новая генерация. Для работы над своим кейсом по-прежнему достаточно открыть папку в агентной среде; второй агент, распознавание речи, MCP и хуки не обязательны.

**Данные и цена.** Для своих материалов нужно право на чтение и, отдельно, на передачу провайдеру: зрение отправляет изображения целиком, интервью — выбранный текст. FFmpeg и локальный Whisper не требуют отправки записей. Для живых вызовов нужны свой доступ в IDE или Codex CLI и разрешённая модель. Длительность и доступные счётчики лежат рядом с каждым результатом; полной цены в рублях и измерений времени реального руководителя нет.
