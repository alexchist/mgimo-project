# Наблюдения фактического consumer-прогона CLI

- `doctor`, `init`, четыре `ingest`, `profile`, пользовательские расчёты и `check` запускались через `/usr/bin/python3`.
- `init` оставил `created_at` пустым; `check` это не считает ошибкой или предупреждением. Это пробел трассируемости, ядро не исправлялось.
- `ingest` не добавляет запись в `runs/operations.csv` автоматически. Импорт пришлось учесть отдельной агрегированной операцией; это риск неполного журнала для свежего пользователя.
- При первом импорте оператор передал `--permission owner-provided` и не передал `--synthetic`, хотя пакет явно синтетический. Метаданные `sources/index.json` исправлены на `permission=synthetic`, `synthetic=true`; hash и извлечения не менялись. CLI поддерживает корректные флаги — это ошибка применения, не дефект экстрактора.
- XLSX extractor всегда сообщает общий пробел о формулах; в проверенном оригинале формул нет. Это консервативное, но неспецифичное предупреждение.
- `profile` сохраняет абсолютный путь к входу, что снижает переносимость артефакта. Hash корректен; ядро не исправлялось.
- Автоматический `check` проверяет структуру и ссылки, но не семантическую достаточность цитат и не согласованность обещаний; это проверено вручную по оригиналам DOCX/XLSX/CSV/HTML.

Сетевых запросов, покупок, публикации, реальных интервью и внешних эффектов не было. Денежная стоимость локального CLI — `not_applicable`; стоимость LLM/подписки среда не сообщила и остаётся `unknown`.
