# Попробовать «Связь для близких» в двух чатах

Вы ведёте семейный тариф. Когда у близкого заканчивается интернет, организатор уже может выделить ему часть общего пакета. Что делать дальше: строить кабинет, предупредить вовремя или оставить всё как есть? Сначала попросите Стратега подготовить встречу. Затем закройте чат и принесите новые данные.

**Что нужно:** Python 3.11+ и агентная IDE с правом читать и записывать файлы и вызывать команды (например, Codex). Для генерации нужен ваш обычный доступ к модели; цена зависит от него. Кейсу не нужны API-ключи в проекте, Poppler, реальные клиентские данные или доступ к сайтам. Локальные команды подготовки и проверки файлов не вызывают модель. Само содержание может передаваться провайдеру вашей IDE.

**Сначала посмотреть, а не запускать:** [запись двух сеансов · MP4, 2:02, с подписями](demo.mp4). [Обе записки, исходные ответы и ограничения опыта](run/README.md).

**Если хотите проверить смену среды:** есть [результат передачи из Codex в Claude Code](../field-kit/handoff/README.md). Для отдельного вопроса про интерфейс — [два учебных экрана передачи гигабайтов](../field-kit/data-share/README.md). Их не нужно открывать, пока проходит основной опыт.

### 1. Из пустого кейса — к записке на встречу

Из корня скачанного репозитория выполните:

```sh
python3 docs/family-link/prepare.py start ../family-lab
```

Откройте **новую папку `../family-lab`** в IDE, не родительский репозиторий. В новый чат вставьте текст `request.txt`. Агент получает [три собственных учебных материала](../../evals/cases/family-link/start/), инструкции и инструменты. В этой учебной папке `AGENTS.md` — только рабочая инструкция. Готовой стратегии, разбора для жюри и будущего уточнения там нет. Справочники дополнительных опытов остаются в исходном репозитории. Имя `family-lab` можно заменить; существующую папку команда не перезапишет.

Дождитесь результата. Откройте `projects/family/decision-memo.md`: какую работу агент предлагает оплатить сейчас? Чем обосновывает совет? Рядом — `options.md` с альтернативами и `strategy.md` с продуктовой и коммуникационной стратегиями. Сохраните работу и **закройте первый чат**. Не переносите его переписку.

### 2. Принесите результаты подсчёта

Вернитесь в терминал **исходного репозитория**, не меняя рабочий кейс вручную:

```sh
python3 docs/family-link/prepare.py update ../family-lab
```

В той же `family-lab` откройте **новый чат** и вставьте текст `update-request.txt`. Вторая команда только положила в `materials/update` [два учебных файла](../../evals/cases/family-link/update/); она сама не меняла ни рекомендации, ни журнал решений. Сопоставьте ответ с таблицей: события могут повторяться, семья считается один раз.

### 3. Проверьте, а не поверьте ответу

Из терминала `family-lab`:

```sh
python3 tools/strategist.py check projects/family
python3 tools/strategist.py resume projects/family
```

Посмотрите **три места**: текущую записку; её прежний текст в `revisions/R-…-before/` внутри кейса; `decisions/decisions.csv`. Советы могут различаться между запусками. Признак полезного пересмотра — читатель видит, какое основание изменилось, что ещё можно проверить в срок и был ли у команды мандат тратить деньги. Успешный `check` сам по себе подтверждает лишь структуру и целостность сохранённых файлов.

**Что именно здесь воспроизводится.** Это короткая учебная версия развилки из [большой пятичастной стратегии](README.md), а не замена исходного PDF или полевой пилот. [Записка для чтения без IDE](reader.pdf) — отдельная редакторская версия исходной позиции с выписками на второй странице, не ответ одного из чатов.
