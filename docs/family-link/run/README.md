# Что изменилось во втором чате

**После теневого подсчёта Стратег предложил оставить обычное обслуживание и перенести тест с клиентами.** Причина не в том, что предупреждение не работает: его никому не отправляли. Изменился ответ на другой вопрос — удастся ли вовремя собрать нужное число разных семей.

| До уточнения | После уточнения |
|---|---|
| [Первая записка](before/decision-memo.md): обсудить до 20 000 ₽ на наблюдение без отправки сообщений. Из [таблицы планирования](before/sources/originals/S-003__design.csv) следует: для 3 600 назначений за девять недель нужны 400 семей в неделю. Реальный поток неизвестен. | [Новая записка](after/decision-memo.md): [четыре строки](after/sources/originals/S-005__shadow.csv#L2) дают 96 + 104 + 98 + 102 = 400 **за весь период**, при 620 событиях с повторами. Если темп сохранится, это 900 подходящих семей за девять недель, ещё до согласий. Для прежнего плана не хватает как минимум 2 700 семей. |
| [Варианты](before/options.md) и [обе стратегии](before/strategy.md): если предупреждение окажется уместным, использовать существующую ручную передачу, не строить новый кабинет. | [Обновлённые варианты](after/options.md) и [обе стратегии](after/strategy.md): проверять, есть ли у организатора время и свободный объём, а не обещать результат пилота к концу квартала. Действующее обещание семье прежнее: на совместимом тарифе можно вручную выделить трафик. |

При 100 назначениях в неделю полная цель требует 36 недель набора, а не девяти; плюс неделя на исход последней семьи. Не все подходящие могут согласиться. Отложена оценка снижения перебоев по **прежнему плану**. Иной полезный эффект, срок или дизайн потребуют нового обоснования. [Журнал решений](after/decisions/decisions.csv) остался без записей: ни один бюджет не утверждён.

### Как был устроен опыт

На Linux работали два отдельных процесса Codex CLI 0.170.0 (`exec --ephemeral`, запрос `gpt-6.2-sol`, medium), без продолжения идентификатора чата. `prepare.py` создал папку без `.git`, прошлых ответов, исходного PDF, оценочных ключей и будущего наблюдения. [Первый запрос](../first.txt) и [три исходника](../../../evals/cases/family-link/start/) → агент создал кейс, сам вызвал инструменты и оставил [ответ](answer-1.md). Организатор сохранил копию **после завершения процесса**, добавил два новых файла командой `update`, затем запустил [второй запрос](../second.txt). У второго агента не было переписки первого; он вызвал `resume`, импортировал материалы и применил `revise` до смысловых правок. [Ответ второго чата](answer-2.md) и [старая записка в его архиве](after/revisions/R-001-before/decision-memo.md). Рабочие документы не отредактированы задним числом. Только в файлах финальных ответов ссылки переведены с временной папки на относительные адреса.

| Измерение | Первый чат | Новый чат |
|---|---:|---:|
| Время процесса модели, с инструментами | 245,5 с | 215,6 с |
| Завершённые команды оболочки (из них с ненулевым кодом) | 21 (3) | 22 (4) |
| Входные токены, кеш в их числе | 477 948 / 406 016 | 679 742 / 605 056 |
| Выходные токены | 10 354 | 8 512 |

[Счётчики и хеши](observations.json). Модель не покупала услуги и не общалась с клиентами. Полная цена модели в рублях и время подготовки или редактуры человеком **не измерены**. Пометка `not_applicable` в локальной операции — не цена вызова Codex. По ходу были ненулевые выходы: в частности `git status` вне Git-папки, поиск инструкции в кратком README без совпадений и проверки через `assert`; агент продолжил самостоятельно. Ведущий не подсказывал команд в ходе сеансов. До записи не запустился экранный рекордер (отсутствовала утилита генерации временного ключа); исправлено до первого модельного вызова.

Из корня репозитория `python3 docs/family-link/replay.py` без API независимо пересчитывает поток и дефицит, проверяет все входы против копий в кейсе, `check` и `resume` для состояний до и после, пять прежних документов побайтно и отсутствие принятого решения. Имена файлов и статусы сами по себе не оценивают смысл совета. Это одиночная демонстрация на собственных учебных данных, а не парное сравнение с обычным чатом, интервью или доказательство экономии. Чтение записки продуктовым руководителем не проводилось.
