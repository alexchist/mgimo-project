**На планёрке стоит обсудить до 20 000 ₽ на разбор причин и наблюдение без отправки сообщений.** Первый кандидат для проверки — организатор общей группы на одном совместимом тарифе. Нужно выяснить, успеет ли он вручную поделиться свободным пакетом, если раньше узнает о риске исчерпания. Для собственной SIM роутера вопрос отдельный — сначала различить неоплату и отключение питания. [Записка к планёрке](before/decision-memo.md)

Обычное обслуживание сохраняет доступную ручную помощь. Предупреждение со ссылкой может ускорить её, если есть время и свободный объём. Новый кабинет стоит обсуждать при подтверждённых трудностях управления группой. Сворачивание разработки освобождает ресурсы, но оставляет гипотезу без проверки. Если разбор покажет, что ранний сигнал редко позволяет помочь, я бы сохранил обычное обслуживание. **90 000 ₽** — предложенный потолок прямых расходов отдельного будущего теста, без разработки.
