# Пересчёт набора после учебного теневого наблюдения

- Входы — [S-003, строки 2–4](../sources/originals/S-003__design.csv#L2) с планом, [S-004, строка 3](../sources/originals/S-004__note.md#L3) с определением и [S-005, строки 2–5](../sources/originals/S-005__shadow.csv#L2) с недельными агрегатами. SHA-256 в [индексе](../sources/index.json). Оригиналы обновления побайтно совпали с входными файлами, текст и ячейки сверены с извлечениями. Четыре последовательные недели без пропусков и дублей недель. Оба счётчика целые и неотрицательные. Уникальность семей за четыре недели дана в записке и по агрегатам отдельно не проверяется.
- Из корня запустить `python3 projects/family/analysis/shadow.py`. [Сохранённый результат](shadow.txt). Прежний [расчёт сценария](design.method.md) описывает исходные параметры.
- 400 / 4 = 100 новых уникальных подходящих семей в неделю. 620 / 4 = 155 событий в неделю, включая повторные. Для набора используется первая колонка счётчиков. 3600 / 9 = 400 **назначаемых** семей в неделю требуется для прежней цели.
- При сохранении учебного темпа 100 × 9 = 900 подходящих семей. Если каждая будет назначена, это 450 на ветвь, 25% общей цели, дефицит 2700. Согласия и прочие отсечения могут уменьшить набор. Если средний темп окажется равен минимуму или максимуму этих четырёх недель, за девять недель будет 864–936 подходящих семей. Это сценарии, статистический интервал здесь не рассчитан. Экстраполяция предполагает сохранение темпа первых уникальных входов, хотя четырёхнедельная таблица этого не проверяет.
- При 100 назначаемых в неделю прежняя цель потребовала бы 36 недель набора, затем неделю на исход последней семьи и время на обработку. Это иллюстрация разрыва с календарём, длительный прогноз отсутствует.
- Предупреждений в учебном наблюдении не было. Согласия, фактическая база семисуточных ограничений, потери исходов, время и свободный объём для помощи и эффект предупреждения из этих данных не определяются. Сценарий 12% → 9% из исходного дизайна остаётся гипотезой. Новую достаточную выборку и полезный эффект по теневой таблице обосновать нельзя.
