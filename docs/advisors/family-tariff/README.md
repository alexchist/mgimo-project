# Разговор и критика предложения о семейном тарифе

В учебном кейсе руководитель выбирает, проверить ли ранний сигнал организатору, подсказку самому участнику или текущий способ помощи. Критерий первого шага — возможность сократить предотвратимый перебой. Согласие и объём доступа организатора ограничивают, где помощь допустима.

## Что было запущено

20 ноября 2026 года в Codex CLI 0.170.0 с входом через ChatGPT прошли четыре хода респондента и отдельный вызов критика. Каждый ответ получен реальным вызовом модели. Семья, события и тариф вымышлены. Разговоров с абонентами и измерений у оператора не было. Ведущий формулировал очередной вопрос после чтения предыдущего ответа. Критик получил [свой пакет](critic-packet.md) без ответов респондента.

| Журнал | Модель и усилие, подтверждённые CLI | Секунды | Что дал ход |
|---|---|---:|---|
| [01](run/01.json) | `gpt-5.6-sol` · `low` | 7,158 | Персонаж сообщил о проблеме через Wi‑Fi, сам купил трафик у остановки. Организатор проверил общий счёт. |
| [02](run/02.json) | `gpt-5.6-sol` · `low` | 8,675 | Вопрос уточнил, где организатор мог опередить самостоятельное пополнение. Модель назвала недоступность приложения и нехватку денег. |
| [03](run/03.json) | `gpt-5.6-sol` · `low` | 6,548 | Вопрос потребовал вспомнить эпизод с этим препятствием. Модель придумала звонок с чужого телефона и покупку трафика организатором. |
| [05](run/05.json) | `gpt-5.6-sol` · `low` | 5,931 | Вопрос оттолкнулся от звонка и уточнил объём сведений. Модель предложила одноразовую помощь по запросу. |
| [04](run/04.json) | `gpt-6.2-astra` · `medium` | 13,641 | Критик предложил оценить верхнюю границу выигрыша, сравнив фактическое время восстановления с самым ранним возможным вмешательством. |

Сумма времени пяти вызовов — 41,953 с. К ней добавляются составление вопросов, чтение и разбор. Эта работа отдельно не хронометрировалась. Во всех журналах денежная стоимость `unknown`. Сравнения с обычным чатом или живым исследователем здесь нет. В ходе прогона предзапусковая проверка конфигурации была усилена. Журнал `05` получен версией с проверкой включённых MCP-серверов, первые четыре журнала получены предыдущей версией запуска с теми же промптами и правилами чтения пакета.

## Вопросы, которые можно проверить

| Откуда | Гипотеза | Проверка и различающий результат |
|---|---|---|
| [01](run/01.json), [02](run/02.json) и [критика](run/04.json) | При доступном Wi‑Fi и возможности купить трафик участник часто выигрывает время без организатора. | На одном тарифе четыре недели сравнивать время текущего восстановления и самое раннее возможное разрешённое действие организатора. Считать все подходящие инциденты, в том числе случаи без сигнала и без возможности помочь. Результат даёт верхнюю оценку выигрыша. Если она ниже заранее выбранного порога пользы на семью в месяц, испытание сигнала отложить. |
| [03](run/03.json) | При недоступном приложении или отсутствии денег путь самостоятельного восстановления может занимать больше времени. | В живом интервью восстановить маршрут последнего эпизода с обеих сторон и выделить момент, когда участие организатора стало возможным. Разделить отсутствие связи, недоступность приложения и нехватку денег. Гипотеза ослабевает, если участники обходят эти препятствия раньше, чем приходит помощь. |
| [05](run/05.json) | Разовый запрос помощи позволит действовать без постоянного доступа организатора. | С согласия дать организатору и участнику выполнить задачу в прототипе с минимальными сведениями и отозвать разрешение. Зафиксировать успешность, время и ошибки доступа. Если права не прекращаются после отзыва или необходимое действие требует дополнительного постоянного доступа, вариант нуждается в пересмотре. |

Гипотезы относятся к механизму и условиям эксперимента. До инвестиционного решения остаётся узнать частоту каждой причины, измерить минуты перебоя и сравнить фактическую пользу вариантов. Для оценки спроса и удержания нужны реальные наблюдения. В живом разговоре поможет гайд. [Согласие, вопросы и разбор](../../../skills/interview/guide.md)

## Повторить

Из корня репозитория выполните команды по одной. `mktemp` создаёт новый каталог журнала. Идентификаторы моделей взяты из этого прогона. Если доступ отличается, явно укажите доступную модель или [выберите новый маршрут](../README.md#журнал-и-исправление-маршрута). Ответы могут отличаться. Используйте готовые вопросы как пример адаптации. Если в вашей первой реплике возник иной эпизод, задайте уточнение по нему и передайте свой UTF-8 файл.

```bash
case_dir=docs/advisors/family-tariff
run_dir=$(mktemp -d)
python3 tools/advisor.py run --via codex --role respondent --model gpt-5.6-sol --effort low \
  --context "$case_dir/respondent.md" --question "$case_dir/opening.txt" --out "$run_dir/01.json"
```

Откройте `01.json` и выберите деталь, от которой зависит следующий вопрос. Если речь снова о самостоятельном пополнении через Wi‑Fi, попробуйте следующие шаги по одному.

```bash
python3 tools/advisor.py run --via codex --role respondent --model gpt-5.6-sol --effort low \
  --context "$case_dir/respondent.md" --question "$case_dir/follow-up-1.txt" \
  --previous "$run_dir/01.json" --out "$run_dir/02.json"

python3 tools/advisor.py run --via codex --role respondent --model gpt-5.6-sol --effort low \
  --context "$case_dir/respondent.md" --question "$case_dir/follow-up-2.txt" \
  --previous "$run_dir/02.json" --out "$run_dir/03.json"

python3 tools/advisor.py run --via codex --role respondent --model gpt-5.6-sol --effort low \
  --context "$case_dir/respondent.md" --question "$case_dir/follow-up-3.txt" \
  --previous "$run_dir/03.json" --out "$run_dir/05.json"
```

Критика запускается отдельной командой и может идти до беседы.

```bash
python3 tools/advisor.py run --via codex --role critic --model gpt-6.2-astra --effort medium \
  --context "$case_dir/critic-packet.md" --question "$case_dir/critic-question.txt" --out "$run_dir/04.json"
```

Для просмотра готового результата используйте журналы из таблицы. Они сохраняют фактические тексты ответов. Для сверки связи, например, SHA-256 файла `run/01.json` должен совпасть с `previous_sha256` в `run/02.json`.

Для запуска с теми же параметрами ролей можно вместо `--model` и `--effort` указать `--profile docs/advisors/profile.example.json`. Сохранённые журналы были получены через явные флаги.
