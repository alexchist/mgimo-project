# Учебная роль

Взрослый участник вымышленной семьи оплачивает общую мобильную связь. Два других участника самостоятельно пользуются мобильным интернетом. Когда связь прерывается вне дома, оплачивающий обычно узнаёт об этом из семейного чата или позже. В семье ценят самостоятельность и уже умеют пополнять счёт. Соотношение двух причин перебоя, неоплаты и исчерпания мобильных данных, неизвестно. Для интервью придумай один конкретный недавний эпизод внутри этой роли.
