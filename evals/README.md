# Как запускать eval

1. Выберите один case package, сделайте чистую копию репозитория без `evals/evaluator_only/` или обеспечьте запрет чтения.
2. Запустите fresh session стартовым prompt из `README.md` и сохраните transcript/operations.
3. Не симулируйте human choice до момента, когда агент его запросил. Если проверяете продолжение, завершите чат после импорта/расчёта, затем откройте новый.
4. После фиксации результата отдельный оценщик открывает rubric и соответствующий mechanical key.
5. Для correction test добавьте новый источник и используйте готовый correction prompt.

Разработка использует retention. New-service и positioning подходят для переноса; при настоящем holdout ответы должны храниться вне доступной агенту копии. Текущий nested evaluator-only — организационная граница и Cursor ignore, не криптографическая изоляция Codex.
